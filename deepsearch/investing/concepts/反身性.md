# 反身性（Reflexivity）

**定义**：市场价格影响基本面，基本面再反过来影响价格，形成自我强化的繁荣/萧条循环——因此"价格围绕均衡价值波动"的假设不成立，错价可以持续且扩大。

**出处**：George Soros《The Alchemy of Finance》（1987）。

**两个回路**：
- **正反馈**：股价上涨 → 融资成本下降/并购能力增强 → 基本面改善 → 股价进一步上涨（如泡沫期的成长股、信贷繁荣）。
- **负反馈**：下跌 → 抵押品缩水/信用收缩 → 基本面恶化 → 进一步下跌（如 2008、银行挤兑）。

**交易含义**：
1. 趋势在反身性阶段**不可逆势**——"市场非理性的时间可以长过你保持有偿付能力的时间"。
2. 拐点的识别信号：基本面开始对价格"脱敏"（好消息不涨/坏消息不跌）。
3. 宏观对冲基金的赔率来自拐点前后的凸性下注，而非预测均衡。
