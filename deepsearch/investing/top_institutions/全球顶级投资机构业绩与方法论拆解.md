## 执行摘要

- 全球范围内**有公开可考、持续 15 年以上**超额收益的机构/个人不超过十余家，年化超额（相对基准）集中在 **5–30 个百分点**，但其方法论可归并为 **五大流派**：深度价值复利、全球宏观反身性、系统化量化、成长调研驱动、配置与风险工程。
- 顶级机构的共性不在"预测更准"，而在三层能力栈：**决策底层框架（期望值 + 能力圈 + 安全边际/凸性）→ 支撑资料获取（一手资料/专有数据/产业链调研）→ 人工核验机制（证伪清单、决策日志、复盘纪律）**。
- 对个人投资者（尤其事件驱动型策略）可迁移的部分：[[安全边际]]、[[能力圈]]、[[期望值与仓位管理]]、[[反身性]] 四个概念 + 决策日志制度。

| 新加坡淡马锡 Temasek | 1974 成立至今 | 成立以来 TSR 约 **15%**（新元） | 20 年维度约 7–9%，近十年回落 | ✅ 官方 Temasek Review 披露[^9^] |
| Universa（Mark Spitznagel，尾部对冲） | 2008 成立至今 | 长期微负（保险费）→ 危机爆发 | 2020 年 3 月单月 +3,612%，Q1 +4,144%（投资者信函） | ⚠️ 信函经媒体报道[^10^] |

**读表要点**：
1. **规模诅咒是普适规律**——Medallion 刻意限制在 ~100 亿美元并封闭；Bridgewater、Berkshire 近十年超额均显著收窄。
2. 可持续超额的三种形态：**高频微小优势×高换手**（Renaissance）、**低频大注×长期持有**（Buffett、Klarman）、**不对称凸性×耐心等待**（Soros、Druckenmiller、Universa）。
3. 数据可信度分层很重要：公募基金/上市公司/主权基金数据可核验；顶级对冲基金（Quantum、Duquesne、Baupost）数据均来自媒体和传记，**引用时须标注"未公开审计"**。

## 二、五大流派方法论拆解

### 流派 1：深度价值 / 质量复利（Buffett、Klarman、Fundsmith）

**决策底层框架**
- 股票 = 企业所有权的一部分，市场报价（Mr. Market）是情绪化的交易对手而非定价权威。
- [[能力圈]]：只投能用一句话说清"它十年后为什么还在赚钱"的生意。
- [[安全边际]]：以显著低于内在价值的价格买入，让估值错误成为利润来源而非风险来源。
- Fundsmith 变体："买好公司，别付太高价，然后什么都不做"（Buy good companies, don't overpay, do nothing）——换手率低至个位数。

**支撑资料获取**
- 一手资料优先：10-K/10-Q、历年股东信、电话会纪要，**不依赖卖方研报**。
- 巴菲特式"翻阅一切"：年轻时通读穆迪手册逐页找烟蒂；如今是财报与行业出版物。
- 定性调研：管理层诚信与资本配置记录（往绩比话术重要）。

**人工核验判断标准**
- 能否估算内在价值区间？估不出来 = 出圈，放弃。
- 管理层是否理性配置资本（回购/并购/分红的往绩）？
- "即使交易所关闭五年，我是否仍愿意持有？"——芒格式反问。
- 预先写下卖出条件，避免持仓后被叙事绑架。

### 流派 2：全球宏观 / 反身性（Soros、Druckenmiller、Dalio）

**决策底层框架**
- [[反身性]]：价格影响基本面，基本面再影响价格，形成自我强化的繁荣/萧条循环——均衡假设不成立，错价可以持续且扩大。
- 不对称凸性下注："重要的不是你对错，而是你对的时候赚多少、错的时候亏多少"（索罗斯）。
- Druckenmiller："当你极度确信时，应该下重注。猪的勇气（It takes courage to be a pig）"。
- Dalio 变体：把宏观决策规则化（债务周期模板 + Pure Alpha 信号集），再用"极度求真/极度透明"的组织机制对冲个人盲区。

**支撑资料获取**
- 宏观数据库：百年跨国的债务/汇率/利率史（Dalio 团队回溯 500 年）。
- 政策一阶信息：央行会议纪要原文、财政立法文本，而非媒体转述。
- 市场微观结构：持仓报告（CFTC COT）、资金流向、期权偏度——判断"谁已经下注"。

**人工核验判断标准**
- 先找反例："什么情况证明我错了？"写在下注之前（pre-mortem）。
- 止损纪律机械化：Soros 的著名习惯是背痛作为风险信号——本质是把不适感制度化为减仓触发器。
- 观点与仓位分离：可以持有观点但零仓位，等待赔率窗口。

### 流派 3：系统化量化（Simons、Thorp、Citadel、Millennium）

**决策底层框架**
- [[期望值与仓位管理]]：不预测单笔结果，只要求大数定律下期望为正 + 严格仓位公式（Thorp 是凯利准则的首批实践者）。
- 统计显著性门槛：Renaissance 要求信号在大量独立样本/市场/时间区间上都成立才纳入。
- 风险工程优先于收益：Millennium 的 PM 回撤熔断（亏 ~7.5% 砍半、~15% 出局）是平台长青的核心机制。

**支撑资料获取**
- 专有数据 + 清洗能力：Renaissance 早期手工数字化 1700 年代以来的数据；数据质量本身是护城河。
- 另类数据：卫星、信用卡流水、招聘数据、航运 AIS。
- 学术文献工业化阅读：Thorp 从数学论文里挖策略，Simons 从语音识别的隐马尔可夫模型借人借方法。

**人工核验判断标准**
- 信号失效检测：容量衰减、拥挤度监控、样本外持续验证。
- "这个优势为什么存在？谁在持续亏钱给我们？"——找不到对手盘来源的信号不可信。
- 人只干预系统层面（模型治理），不干预单笔交易。

### 流派 4：成长 / 调研驱动（Lynch、Baillie Gifford、高瓴）

**决策底层框架**
- Lynch：六类公司分类（缓慢增长/稳健/快速成长/周期/困境反转/隐蔽资产），不同类型用不同估值锚和卖出规则。
- PEG 与"故事-数字一致性"：成长性必须能被单位经济模型验证。
- 高瓴："长期结构性价值投资"——投生意模式与组织，而非投价格缺口。

**支撑资料获取**
- 草根调研（channel check）：Lynch 一年拜访 200+ 公司、阅读 700 份年报；从消费一线发现 tenbagger。
- 产业链交叉验证：供应商、渠道商、竞对访谈（高瓴式深度行研）。
- 内部人行为：管理层增持/回购是比话术更硬的信号。

**人工核验判断标准**
- "两分钟内能对十一岁小孩讲清这家公司的故事"（Lynch 规则）。
- 跟踪 story drift：买入理由的每个关键假设是否还成立？破一条就复核。
- 警惕线性外推：Baillie Gifford 2021–22 的教训——成长叙事的赔率会随估值恶化。

### 流派 5：配置与风险工程（Swensen、NBIM、Universa）

**决策底层框架**
- 收益的主要来源是**资产配置**而非选券（Swensen 的实证起点）。
- 再平衡纪律：机械地"高卖低买"，把波动转化为收益。
- Universa/尾部对冲：承认不可预测，购买凸性——平时持续付小额保险费，危机时获得指数级赔付，组合层面反而提升长期 CAGR（数学上来自波动率拖累的削减）。

**支撑资料获取**
- 超长周期回报数据（百年股债房商品实际回报）。
- 管理人尽调体系（耶鲁模式的真正壁垒是筛选外部 GP 的能力与准入）。

**人工核验判断标准**
- 再平衡规则事先写死，危机中不临时修改。
- 尾部保护的成本预算化（如每年组合价值的固定 bps），不因"最近很平静"而取消。

## 三、横向提炼：顶级机构的统一能力栈

把五派的方法论压到同一框架，可拆为三层：

### 第 1 层：决策底层框架（人人可学）

| 要素 | 代表 | 一句话 |
|---|---|---|
| 期望值思维 | Thorp / Renaissance | 不预测，只下注于正期望 |
| [[能力圈]] | Buffett / Lynch | 估不出价值的直接放弃 |
| [[安全边际]] / 凸性 | Klarman / Universa | 错误要成为利润来源 |
| 不对称赔率 | Soros / Druckenmiller | 对错不重要，盈亏比重要 |
| [[反身性]] | Soros | 趋势会自我强化，也会自我毁灭 |
| 证伪优先 | Dalio / Munger | 先写"什么情况我错了" |
| 逆向思考 | Munger | "反过来想，总是反过来想" |

### 第 2 层：支撑资料获取（资源密集，可部分迁移）

| 手段 | 代表 | 个人可迁移性 |
|---|---|---|
| 一手财报/公告/纪要原文 | 全流派共识 | ✅ 完全可迁移（SEC/港交所/巨潮） |
| 草根调研/产业链访谈 | Lynch / 高瓴 | ✅ 小规模可做（消费体验、行业群、专家访谈） |
| 宏观长周期数据库 | Bridgewater | ⚠️ 可用 FRED/世界银行/免费宏观库替代 |
| 专有数据与清洗 | Renaissance | ❌ 不可迁移，个人应避开正面竞争 |
| 另类数据 | 量化机构 | ⚠️ 免费残羹（招聘网站、Google Trends、航运公开数据） |
| 期权市场隐含信息（IV、偏度、持仓） | 宏观/事件驱动机构 | ✅ 可迁移——这正是 [[earnings-iv-strategy]] 的信息源 |

**核心洞察**：个人在"数据获取"上打不过机构，但在**数据耐心**（读完十年股东信）、**时间套利**（机构的季度考核 vs 个人的无限久期）和**事件利基**（小到机构看不上/进不来的容量）上反而有优势。

### 第 3 层：人工核验判断标准（纪律密集，决定成败）

顶级机构制度化的核验机制，按执行顺序：

1. **下注前**：pre-mortem（"假设这笔投资失败了，最可能的原因是？"）+ 证伪条件书面化 + 卖出规则预先写死。
2. **持有中**：story drift 检查（关键假设逐条复核）；仓位与确信度匹配（Druckenmiller：极度确信才允许重仓；Renaissance：信号强度决定仓位）；不适信号制度化（Soros 的背痛 → 减仓）。
3. **结算后**：决策日志复盘——区分**决策质量**与**结果质量**（Dalio 的痛苦+反思=进步；Annie Duke 的 resulting 谬误警告）。所有顶级机构都有某种形式的决策日志制度，这是唯一能把经验转化为复利能力的机制。

## 四、对个人投资者的迁移清单（结合 [[earnings-iv-strategy]]）

| 能力栈 | 机构做法 | 个人可执行版本 |
|---|---|---|
| 决策框架 | 期望值 + 凸性 + 能力圈 | 每笔交易前写三行：期望来源（IV crush？方向？）、最坏情形、证伪条件 |
| 资料获取 | 一手资料 + 调研 | 财报原文 + 电话会纪要 + 期权链 IV/偏度数据（longbridge）+ 行业交叉验证 |
| 人工核验 | pre-mortem + 决策日志 | 交易日志模板化：入场理由/赔率/证伪点 → 结算后复盘决策质量而非盈亏 |
| 规模优势 | —— | 只做机构容量外的利基：个股财报事件、小市值、期权流动性的犄角旮旯 |
| 时间套利 | 无限久期 vs 季度考核 | 不在财报前被迫表达观点；可以整季空仓等赔率窗口（Druckenmiller："观点与仓位分离"） |

**警示（数据红线）**：Quantum、Duquesne、Baupost、Citadel、Millennium 的回报数字均未经公开审计，取自传记与媒体，引用时必须保留此限定；**不要**把"约 30%"当作可复制的目标——这些是幸存者中的幸存者。
